# projectnura

Nuradesk - Modern, intuitive, and lightning-fast cloud POS & Admin Suite for restaurants, cafes, retail, and modern businesses.

## Features
- **Modern Landing Page**: Rich UI showcasing key POS hardware and software features.
- **Full Onboarding Flow**: 9-step guided setup with outlet configuration, selling channels, billing, tax rules, payment methods, and pricing plans.
- **2FA Authenticator Screen**: Segmented OTP code verification for secure admin access.
- **Admin Panel**: Centralized management for orders, inventory, terminals, outlets, and sales reports.

## Getting Started
```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
